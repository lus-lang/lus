# Third-party notices for the Lus site archive

The Lus site redistributes the browser WASM runtime and its components, its
embedded language server, three self-hosted fonts, modern-monaco editor
code, and Lucide icon paths. The complete license texts ship beside this
notice.

and other build tools remain in the build environment.
