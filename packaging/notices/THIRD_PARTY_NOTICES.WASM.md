# Third-party notices for Lus WASM archives

Lus WASM archives contain the WebAssembly runtime, the `lus-wasm`
JavaScript host, and the embedded Lus language server. The runtime compiles
the components listed below into the module. The language server retains
lineage from the Lua language server. The complete license texts ship
beside this notice.

| Component | License file |
| --- | --- |
| Brotli | `LICENSE.BROTLI.txt` |
| IANA time zone database | `LICENSE.TZDATA.txt` |
| Lua | `LICENSE.LUA.txt` |
| Lua language server lineage | `LICENSE.LUALS.txt` |
| SQLite | `LICENSE.SQLITE.txt` |
| Unicode and CLDR data | `LICENSE.UNICODE.txt` |
| wasi-libc | `LICENSE.WASI-LIBC.txt` |
| Zig standard library and compiler runtime | `LICENSE.ZIG.txt` |
| Zstandard | `LICENSE.ZSTD.txt` |
