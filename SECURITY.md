## Reporting a vulnerability

Report vulnerabilities privately with [GitHub's advisory form](https://github.com/lus-lang/lus/security/advisories/new). Your report stays private between you and the maintainer until a fix ships. The published advisory credits you unless you ask otherwise.

Include the version, the platform, and a program or input that reproduces the problem. Escapes from the permission system (`pledge`), memory safety bugs in the runtime or the JIT, and bugs in the TLS, archive, or JSON parsers are the most valuable reports.

Please keep vulnerabilities out of public issues, pull requests, and Discussions until the advisory is published.
