# [Lus](https://lus.dev)

A small, fast, and productive language to build programs.

[Instructions for using Lus can be found here.](https://lus.dev/manual/getting-started/)

## Project tree

- [**`/runtime`**](runtime): The runtime, the standard library, and the `lus` command line tools
- [**`/packages/wasm`**](packages/wasm): The runtime as a WebAssembly module with its JavaScript host
- [**`/tests`**](tests): Conformance, embedding, tool, and benchmark tests for the runtime
- [**`/spec`**](spec): Standard library specification and design notes
- [**`/packages/language-server`**](packages/language-server): Language server for Lus
- [**`/packages/vscode`**](packages/vscode): VS Code extension for Lus
- [**`/packages/textmate`**](packages/textmate): TextMate grammar for Lus
- [**`/packages/site`**](packages/site): Source code of lus.dev
- [**`/examples`**](examples): Runnable example programs shown on lus.dev
- [**`/packaging`**](packaging): Install scripts, release keys, notices, and dependency licenses
- [**`/tools`**](tools): Generators and repository checks
- [**`/.agents`**](.agents): Skills and documentation index for coding agents
