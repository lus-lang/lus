This page installs Lus, runs a first program, and introduces permissions, which a program must acquire before it reads a file, opens a connection, or reads the environment.

## Install automatically

On Linux and macOS, run this command in a terminal:

```bash
curl -fsSL https://lus.dev/install.sh | sh
```

On Windows, download and run **[lus-setup.exe](https://github.com/lus-lang/lus/releases/latest/download/lus-setup.exe)**, then follow the prompts. The installer installs the x86_64 build. On Windows for ARM, unpack the aarch64 archive as [Install manually](#install-manually) describes.

On platforms without prebuilt archives, such as the BSDs and illumos, build from source as [Compiling Lus](/manual/compiling) describes.

Check the installation by printing the version:

```bash
lus -v
```

## Install manually

To install without the script, download the release archive for your platform and unpack it. The interpreter is `bin/lus` inside the archive.

## Hello, Lus

Create a file named `hello.lus`:

```lus
local name = "Lus"
print(`Hello, $name!`)   --> Hello, Lus!
```

Run it:

```bash
lus hello.lus
```

A string between backticks is an interpolated string, which replaces `$name` with the value of the variable. The `-->` comment shows what the line prints.

## A first real program

JSON, CSV, files, HTTP, and SQLite are part of the standard library, so a useful program needs nothing beyond `lus`. The following program reads an order from JSON text and prints a receipt. Save it as `order.lus` and run it with `lus order.lus`:

```lus
local order = fromjson([[
    {
        "customer": "Ada",
        "items": [
            { "name": "tea", "price": 4.5, "count": 2 },
            { "name": "scone", "price": 3.25, "count": 1 }
        ]
    }
]])

local total = 0
for _, item in ipairs(order.items) do
    print(`$(item.count) x $(item.name)`)
    total = total + item.price * item.count
end
print(`$(order.customer) owes $(string.format("%.2f", total))`)
--> 2 x tea
--> 1 x scone
--> Ada owes 12.25
```

The program uses four things that the [guide](/manual/guide) explains in full:

- `fromjson` turns JSON text into tables. A _table_ is the data structure that Lus uses for both lists, such as `order.items`, and records with named fields, such as `item.price`.
- `[[` and `]]` enclose a string that spans several lines.
- `for _, item in ipairs(...)` visits each element of a list in order.
- `$(...)` inside an interpolated string inserts the value of any expression.

Bad input raises an error. `catch` runs an expression and returns `false` and the error when it fails, so the program can respond:

```lus
local ok, err = catch fromjson("{oops")
print(ok, err)   --> false  JSON parse error at position 2: expected string key in object
```

## Asking for permission

A Lus program starts with no access to files, the network, other processes, or environment variables. It acquires each capability by calling `pledge`. The following program reads the name of the current user from the environment, which requires the `env` permission:

```lus
pledge("env")

local user = os.getenv("USER") or "stranger"
print(`Hello, $user!`)
```

Without the `pledge` line, the program stops at `os.getenv` with the error `permission "env" denied for 'USER'`. Reading a file requires `pledge("fs:read")` in the same way, and an HTTP request requires `pledge("network")`. The person who runs a script can also set the limit from outside. A script started with `-P` options, as in `lus -Pfs:read=./data/* script.lus`, can do only what those options grant, so a script you have not read cannot reach anything else. [Permissions](/manual/permissions) describes every capability and how to narrow one to a single path or host.
