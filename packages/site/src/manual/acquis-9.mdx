The `network` library provides TCP, UDP, and HTTP or HTTPS networking with native TLS support. Calls require the corresponding `network:http`, `network:tcp`, or `network:udp` pledge.

## HTTP requests

`network.fetch` takes positional arguments in the order `url`, `method`, `headers`, and `body`. The method defaults to `"GET"`. It returns the integer status code, response body string, and a table whose response header names are lowercase. Response bodies are capped at 64 MiB.

```lus
local status, body, headers = network.fetch("https://httpbin.org/get")
print(status)
print(#body)
print(headers["content-type"])
```

The optional values keep their positions for requests that include headers or a body.

```lus
local status, body = network.fetch(
    "https://httpbin.org/post",
    "POST",
    { ["Content-Type"] = "application/json" },
    '{"name":"Lus"}'
)
```

Network and protocol failures raise errors that can be caught.

```lus
local ok, err = catch network.fetch("https://invalid.host.example")
if not ok then
    print("Request failed:", err)
end
```

## TCP connections

`network.tcp.connect(host, port)` returns a client socket. The socket supports `send`, `receive`, `settimeout`, and `close`.

```lus
local socket = network.tcp.connect("example.com", 80)
socket:settimeout(5)
socket:send("GET / HTTP/1.0\r\nHost: example.com\r\n\r\n")
local response = socket:receive("*a")
socket:close()
```

### Receive patterns and limits

`socket:receive(pattern, max_bytes)` accepts three patterns.

| Pattern | Result | Limit |
| --- | --- | --- |
| A positive integer | Reads that many bytes, or the available prefix at EOF | At most 1 MiB |
| `"*l"` | Reads one line and removes its trailing LF and optional CR | 1 MiB by default |
| `"*a"` | Reads through EOF | 64 MiB by default |

The optional positive integer `max_bytes` applies to `"*l"` and `"*a"`. A line or stream that exceeds its limit closes the socket and raises `"receive limit exceeded"`. A numeric receive size is always limited to 1 MiB.

```lus
local header = socket:receive("*l", 8192)
local body = socket:receive("*a", 8 * 1024 * 1024)
```

## TCP servers

`network.tcp.bind(host, port, backlog)` returns a listening server. Port `0` asks the operating system to select a port. `server:getsockname()` returns the bound address and effective port, which makes that form useful for local services and tests.

```lus
local server = network.tcp.bind("127.0.0.1", 0)
local address, port = server:getsockname()
print(`listening on $address:$port`)

local client = server:accept()
local request = client:receive("*l", 8192)
client:send("HTTP/1.0 200 OK\r\n\r\nHello!\n")
client:close()
server:close()
```

The server also supports `settimeout` and `close`. Accepted clients use the TCP client socket methods.

## UDP sockets

`network.udp.open(port, address)` creates a UDP socket and can bind it immediately. An unbound socket can later call `setsockname(address, port)`. `getsockname()` returns the current local address and port for either form.

```lus
local receiver = network.udp.open(0, "127.0.0.1")
local _, port = receiver:getsockname()

local sender = network.udp.open()
sender:sendto("Hello UDP", "127.0.0.1", port)

local data, address, sender_port = receiver:receive()
print(data, address, sender_port)

sender:close()
receiver:close()
```

`receive(size)` defaults to 8 KiB and accepts a maximum of 1 MiB. It returns the datagram prefix up to that size together with the sender address and port. UDP sockets also support `close`.
