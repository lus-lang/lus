## lus

```
lus [options] [script [args]]
lus <command> [arguments]
```

The `lus` executable runs scripts and carries the tools of a Lus project as commands. With no command, or with `run`, it runs a script.

| Command | Purpose |
| --- | --- |
| `run` | Run a Lus script (the default). |
| `test` | Run tests: functions ending in `_test` in `*_test.lus` files. |
| `fmt` | Format source files. |
| `check` | Check source files for errors and lint warnings. |
| `doc` | Generate API documentation from doc comments. |
| `ast` | Print the syntax tree of a file as JSON. |
| `build` | Bundle a script into a standalone executable. |
| `compile` | Compile a script to a binary chunk. |
| `debug` | Run a script under the Debug Adapter Protocol. |
| `help` | Print the standard library reference for a name. |
| `agents` | Set a project up for coding agents. |

### Options

| Option | Effect |
| --- | --- |
| `-e stat` | Execute the string `stat`. |
| `-i` | Enter interactive mode after executing `script`. |
| `-l mod` | Require library `mod` into global `mod`. |
| `-l g=mod` | Require library `mod` into global `g`. |
| `-v`, `--version` | Show version information. |
| `-E` | Ignore environment variables such as `LUS_PATH`. |
| `-W` | Turn warnings on. |
| `-P perm`, `--pledge perm` | Grant a [permission](/manual/acquis-10), such as `-Pfs:read` or `-Pnetwork`. |
| `-F name[=value]`, `--flag name[=value]` | Define a readonly [compile-time flag](/manual/acquis-28). No value means `true`, a numeric value is a number, and anything else is a string. |
| `--include path[:alias]` | [Preinclude](/manual/acquis-29) a module file or directory so `require` finds it without `load` or `fs` permissions. |
| `--readonly-env` | Freeze `_ENV` and the module tables after startup. |
| `--gc-pause N` | Let the heap grow by N percent of its live size before a collection starts. Lower values trade CPU for lower peak memory. |
| `--dis` | Print the bytecode of the script instead of running it. The script compiles exactly as it would run, so the listing reflects the flags given with `-F`. |
| `--` | Stop handling options. |
| `-` | Stop handling options and execute standard input. |

## lus test

```
lus test [options] [path ...]
```

Runs the tests in the named files, or in every `*_test.lus` file below the named directories, the current directory by default. Each file runs in its own process and temporary directory, and files run in parallel. [Acquis 38](/manual/acquis-38) describes how to write tests.

| Option | Effect |
| --- | --- |
| `-v` | List skipped tests and the output of passing files too. |
| `--filter TEXT` | Run only the tests whose names contain `TEXT`. |
| `-u`, `--update` | Rewrite snapshots that no longer match. |
| `--json` | Print one JSON record per test. |
| `--jobs N` | Run at most N files at once (default: the number of processors). |
| `--timeout S` | Stop a file that writes no output for S seconds (default: 60). |
| `--file-timeout S` | Stop a file that runs longer than S seconds in all (default: ten times the timeout). |

## lus fmt

```
lus fmt [--check] [--write] [--indent N] [path ...]
```

Prints the formatted text of each file to standard output. A directory stands for every `.lus` file below it. With no file, or with the file `-`, it reads standard input.

| Option | Effect |
| --- | --- |
| `--check` | Change nothing and list the files that are not formatted (exit 1 if any). |
| `--write` | Rewrite the files in place. |
| `--indent N` | Spaces per indentation level (default: 4). |

## lus check

```
lus check [--json] [--list] [path ...]
```

Parses, lints, and compiles each file without running it and prints each problem as `file:line:column: severity: message [code]`. A directory stands for every `.lus` file below it, and files named `*_test.lus` are checked with the conventions of `lus test`. The exit status is 1 when anything is reported.

| Option | Effect |
| --- | --- |
| `--json` | Print the diagnostics as one JSON array. |
| `--list` | Print every diagnostic code with its severity and summary. |

## lus doc

```
lus doc [-o DIR] [--format md|json] file ...
```

Generates reference documentation from `---` doc comments, one module per file.

| Option | Effect |
| --- | --- |
| `-o DIR` | Write one file per module into `DIR` instead of standard output. |
| `--format md\|json` | Output format (default: `md`). |

## lus ast

```
lus ast [--no-comments] [--no-recover] file
```

Prints the syntax tree of a file as JSON, in the shape that [`debug.parse`](/manual/acquis-12) returns.

| Option | Effect |
| --- | --- |
| `--no-comments` | Leave comments out of the tree. |
| `--no-recover` | Stop at the first syntax error. |

## lus build

```
lus build [options] script
```

Bundles a script and every module it requires by a literal name into a standalone executable. [Acquis 39](/manual/acquis-39) describes the bundle.

| Option | Effect |
| --- | --- |
| `-o FILE` | Write the executable to `FILE` (default: the script name without its extension). |
| `-P perm`, `--pledge perm` | Grant a permission every time the program runs. |
| `-F name[=value]`, `--flag name[=value]` | Define a compile-time flag. |
| `--include path[:alias]` | Bundle a module file or directory even when no literal `require` names it. |

## lus compile

```
lus compile [options] script
```

Compiles a script to a binary chunk, the same chunk that [`string.dump`](/manual/api#string.dump) writes for the compiled script. `lus` runs the chunk directly, and `load` reads it in binary mode. The default output is the script name with the extension `.lusc`.

| Option | Effect |
| --- | --- |
| `-o FILE` | Write the chunk to `FILE`. |
| `-s`, `--strip` | Leave out debug information. |
| `-F name[=value]`, `--flag name[=value]` | Define a compile-time flag, which folds into the chunk. |

## lus debug

```
lus debug [--stdio | --port N] [-P perm]... [script [args]]
```

Runs a script under the Debug Adapter Protocol for editors such as VS Code. [Acquis 40](/manual/acquis-40) describes the debugger.

| Option | Effect |
| --- | --- |
| `--stdio` | Speak the protocol on standard input and output (the default). |
| `--port N` | Accept one client on `127.0.0.1:N`. |
| `-P perm`, `--pledge perm` | Grant a permission to the program. |

## lus help

```
lus help [name | module | --search text]
```

Prints the standard library reference compiled into the executable, so it matches the running version. A name such as `string.find` or `tcp_socket:receive` prints the signature, the permissions the call needs, the stability, and the description. A module such as `fs.path` lists its entries, and no argument lists the modules. A name that matches nothing lists the names that contain it, with exit status 1.

| Option | Effect |
| --- | --- |
| `--search text`, `-s text` | List the entries whose name or description mentions `text`. |

## lus agents

```
lus agents init [dir]
```

Writes the agent skills of the running version into `dir/.agents/skills`, the current directory by default, links `.claude/skills` to them, and adds a Lus section to `AGENTS.md`. Running it again updates the skills. The [agents page](/agents) lists the skills and the prompts to start from.

Building the executable itself is covered in [Compiling Lus](/manual/compiling).
